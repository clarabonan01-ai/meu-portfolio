# Meu Site React Organizado

Projeto reorganizado no padrão:

- `components/` para peças reutilizáveis
- `sections/` para blocos grandes da página
- `data/` para os dados do site

## Como rodar

```bash
npm install
npm run dev
```

## Estrutura

```bash
src/
  components/
  sections/
  data/
  App.jsx
  main.jsx
  styles.css
```
